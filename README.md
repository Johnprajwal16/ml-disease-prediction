# ML Disease Prediction Tool

## Overview
This project implements an end-to-end machine learning pipeline for predicting diabetes risk using clinical health data.

## Key Features
- Engineered feature pipelines producing 10+ training datasets
- Automated dataset generation for retraining and evaluation
- Reproducible model training and metrics tracking
- Clean separation of ingestion, transformation, and modeling layers

## Dataset
Pima Indians Diabetes Dataset (publicly available)

## Workflow
1. Load raw medical data
2. Generate multiple feature-engineered datasets
3. Train ML models
4. Evaluate performance across variants

## Tech Stack
Python, Pandas, scikit-learn
